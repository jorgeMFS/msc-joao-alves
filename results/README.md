Os ficheiros desta pasta têm informações sobre as amostras utilizadas.

sampleinfo contém informação sumarizada sobre cada intervenção, incluindo:
- ano
- número de machos e fêmeas
- número de amostras

table_ITP_Lifespan_Data tem informação sobre cada amostra ITP das cohorts que vão ser utilizadas:
- cohort
- site
- sexo
- id
- grupo
- idade
- flag de censura

flag_censura=1 indica que o ratinho morreu
flag_censura=0 indica que o ratinho foi removido

table_Zenodo tem informação sobre amostras do ITP das cohorts que vão ser utilizadas:
- amostra
- cohort
- laboratório
- espécie
- strain
- sexo
- tecido
- grupo
- intervenção
entre outras informações...

table_zenodo_mpd_id é uma tabela com a correspondência entre a nomenclatura dos fármacos utilizados pelo ITP e pelo Zenodo
